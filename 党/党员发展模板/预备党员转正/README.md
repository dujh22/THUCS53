## ⚠️ 使用要点

- 所有材料严禁抄袭，各份材料之间不得互相复制粘贴、大段雷同。
- 转正申请报告 2000 字以上（标题宋体三号，正文宋体小四单倍行距），须对照志愿书 P9 支部决议中提到的缺点写改正情况，签名并落款，日期在预备期满前 1 周。
- 最终提交系党办的纸质材料：入党志愿书、转正申请报告、预备党员按期转为正式党员票决情况汇总表、预备党员教育考察登记表。半年一次的思想汇报只交电子版。
- 完整流程与填表细则见[党口业务 · 预备党员转正式党员](../../党口业务.md#预备党员转正式党员)。
