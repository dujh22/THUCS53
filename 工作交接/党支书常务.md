# 党支书常规事务

## 查档

请联系党支书完成以下工作，注意查档需要预约，所以要提前至少1个工作日，具体时间参照清华大学档案馆——服务指南——查档须知进行了解：

1. 党支书登录微信公众号：清华大学档案馆——服务指南——填写相关申请表（人事档案服务在线申办）
2. 党支书或党支书指定委员到系办开局委托查档证明
3. 党支书或党支书指定委员带证明去档案馆查档

## 支部计划

【党支部工作计划、党员活动日】：按照学校通知要求，各支部需于【9月8日（下周二）前】完成本学期党支部工作计划（包括总体工作思路和2026年8月-2027年1月每月工作安排）的填报和“党员活动日”（不少于6次，每月至少1次）的设置。

具体填报方式：登录info党组织党员管理系统→切换党支部权限→党组织管理→党支部工作计划/党员活动日。

本学期学生党支部组织生活安排，将由党建辅导员、党建助理另行通知。

## 党费收缴

本月党费已开放交纳，25号截止。请务必于本月25号前完成支部全体党员的党费交纳。查看未交纳党费人员名单路径：info党员管理系统-支部权限-党费管理-党费交纳明细。

## 党员发展

2026年秋季学期发展党员工作已启动，各支部除配合党建辅导员和党建助理完成发展计划的制定报送、外调信息统计外，请通知支部拟本学期发展的同学按照以下模板准备入党材料，各支部承担材料审核的职责，充分运用《入党材料自查清单》（见压缩包），逐项对照核查，严把材料质量关。

本次材料提交时间为9月7日（周一）前，电子版发邮箱：yang_bo@mail.tsinghua.edu.cn。(注：所提交材料应为支部审核后材料)。

入党材料讲解时间另行通知。

确定发展对象后，系党委召开党员发展预审会，支书需为每位发展对象准备一页 PPT 和 1～2 分钟汇报稿（思想 / 现实表现 / 不足 / 导师意见 / 支部推荐）。2026 秋批次的定稿与撰写经验见[党员发展材料 · 2026 秋发展预审会](../党/党员发展材料/2026秋-发展预审会/README.md)，可直接套用版式。

### 预备党员转正

系党委 2026 年 10 月 20 日《关于近期预备党员转正工作的提示》，支书按下列顺序推进（模板见[党员发展模板 · 预备党员转正](../党/党员发展模板/预备党员转正/README.md)，材料填写细则见[党口业务](../党/党口业务.md#预备党员转正式党员)）：

| 时间节点 | 支书动作 |
| :--- | :--- |
| 预备期满前 1 周 | 收预备党员书面转正申请报告（2000 字以上，对照志愿书 P9 缺点写改进） |
| 预备期满前 | 到系党办开介绍信，去档案馆借回入党志愿书；征求党小组、党员和群众意见；召开支委会审查，起草拟讨论转正的决定 |
| 预备期满后 | 到系党办打印公示书并公示，不少于 5 个工作日 |
| 预备期满后 1 个月内 | 公示结束后召开支部党员大会：按议程主持，无记名投票（设监票人、计票人，本人不回避），填写票决汇总表，在志愿书 P11 填支部决议（须写明公示无异议） |
| 转正会后 1 周内 | 纸质材料交系党办：入党志愿书、转正申请报告、预备党员教育考察登记表、票决汇总表 |
| 转正会后 | info 党组织党员管理系统 → 党员管理 → 预备党员转正板块：上传支部决议和转正申请报告 |
