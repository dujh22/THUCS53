# 4. 新生相关

1. 建立新生群
2. 准备新生信息收集：
   ```bash
   @所有人 各位同学好，我是计研五三的带班助理兼党支部书记杜晋华（22级博-唐杰），很高兴认识大家，可以理解我的角色是研究生阶段的辅导员，后续有任何科研学习工作生活心理上需要支持和沟通的问题都欢迎找我

   计研五三支部是计算机系的样板支部，在过去几年里我们先后获评卓越班团、甲级班团、先进党支部等校级荣誉，也希望在各位的加入下支部越来越好。班级网页在 https://dujh22.github.io/THUCS53/

   1. 请各位同学尽快修改群备注
   2. 没加我微信的也请加我下方便联系
   3. 每一届需要1位【新生班长】，请有意向同学联系我截止本周三/明晚24点；我们支部完整班级为纵向班级，包含各课题组各年龄段同学，常设岗位目前空缺【班级副助理】和【文体委员】，有相关意向同学也请随时联系我，或直接在下表中填写
   4. 请于本周三/明晚24点前填写【腾讯文档】计研五三新生信息收集表 https://docs.qq.com/form/page/DUHdDaGVGTEp4Tmxh
   5. 请扫码加入班群，党员请扫码加入党员群
   ```
3. 开展新生班会（组织：带班助理），流程四步：
   1. **集体情况介绍**：参照 `公示/助理年度汇报` 已有 PPT，介绍支部概况、荣誉、组织架构与日常运转
   2. **成员个人介绍**：先逐一介绍班级各社工岗位（谁负责什么，名单见 `班/班级成员.md`），再请新生依次自我介绍（素材来自新生信息收集表"介绍你自己"一栏）
   3. **当月组织生活**：与新生班会合办，由当月轮值负责人主讲（参考 `活动/组织生活/2026-08德育.md`）
   4. **答疑**：回应新生信息收集表中"想沟通的问题/困惑"，并开放现场自由提问
   - 班会 PPT 存放于 `公示/相关PPT/`（如：`2608：计研五三新生班会-杜晋华.pptx`）
