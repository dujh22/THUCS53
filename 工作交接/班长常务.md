# 班长常规事务

> 计研五三为纵向班级，每届新生单独设 1 位**新生班长**，一般由当届新生党员担任，可同时兼任党支委（系里建议分管团务、"一二·九"合唱动员与新生相关工作）。历史任职见[班级成员](../班/班级成员.md)，岗位产生方式见[带班助理常务](带班助理常务.md)"新生相关"。

## 1. 新生入学季

1. 配合带班助理建立新生群，督促同学按「姓名-年级-导师」修改群备注（如：杜晋华-直博一-唐杰）
2. 收回新生信息收集表（腾讯文档），核对学号、导师、学生类别、联系方式，作为[班级成员](../班/班级成员.md)与班级全覆盖的底稿
3. 到系里领取新生研究生证后逐人发放（领取联系人以当年通知为准，如刘天禹师兄）
4. 新生班会时介绍班级岗位分工，配合带班助理完成新生自我介绍环节
5. 推举新生支委与班委（文体委员等），报带班助理确认

## 2. 日常通知与信息传达

1. 班级群「计研五三班级群-软件所」为主要通知渠道，重要通知同步到新生群与党员群；本仓库[班/通知](../班/通知.md)仅为存档，不是首发渠道
2. 每周参加（或接收）研工组周会信息，把与班级相关的条目整理后发班群；已整理的周会在[研工组周会信息公示](../班/研工组周会信息公示.md)
3. 完成研究生信息全覆盖：核对每位同学的邮箱、电话等联系方式，确保真实有效，后续部分通知只按全覆盖联系方式点对点发送
4. 学校、系里的评奖评优、调寝、体检、就业去向填报等通知，负责转达、催办与材料汇总

## 3. 活动与班务配合

1. 每月组织生活/集体活动前，确认所有新生、流动党员（名单问党支书）与班级大群都已通知到位；签到由纪检委员负责，班长配合二次确认未到场同学
2. 班级文体活动由文体委员牵头，班长协助动员与场地、物资协调
3. 班级经费：本支部目前不集中收班费，活动经费走班级/支部所申请的项目，报销材料由经办人留存
4. 需要对外投稿的推送，按[班级业务](../班/班级业务.md)"推送"一节的流程，提供图文 word 稿给带班助理

## 4. 毕业季

1. 提前统计拟毕业名单（见[拟毕业情况](../班/拟毕业情况.md)），核对学术活动、学术报告记录是否满足毕业要求
2. 提醒毕业生完成就业去向填报等 DDL，配合毕业生评奖评优（优秀毕业生、优良毕业生、三好学生等）材料收集与公示
3. 毕业生离校后更新班级成员名单，把同学移入毕业群

## 5. 与其他岗位的分工

| 岗位 | 班长需要对接的事 |
| :--- | :--- |
| 带班助理 / 副助理 | 信息传达、新生工作、突发情况上报，班长直接向带班助理汇报 |
| 党支书 | 流动党员名单、入党动员、组织生活与活动通知 |
| 团支书 | 团务、推优入党、"一二·九"合唱动员 |
| 纪检委员 | 活动签到与未到场二次确认 |
| 文体委员 | 班级文体活动的动员与组织 |
| 组织/宣传委员 | 活动问卷发放、活动总结稿校验 |

## 6. 定期谈话指南

定期谈话是计算机系研工组的统一要求，目的是尽早发现同学在学业、就业、身心和生活上的困难。带班助理要覆盖多个年级，因此委派各届班长负责本年级同学的谈话。

### 谈话形式与设备

1. 班上配有一台录音设备，所有谈话都要存档录音，线上、线下均可
2. 只有一台设备，各届轮流使用，每届连续使用 4～5 周，期间每周谈 2～4 名同学（本年级全覆盖一轮后交接给下一届）
3. 谈话时长原则上不少于 1 分钟，不设上限
4. 录音设备的转写功能由设备自身提供。若设备需要注册手机号而名额受限，可联系带班助理统一注册、统一共享使用

### 录音告知（谈话开始前必须说明）

1. 录音需征得同学本人同意，不同意的可以只做记录不录音
2. 说明录音仅用于审核班长的谈话表述是否规范到位，不用于评价同学本人
3. 说明数据只存放在计算机系的私有存储中，不对外开放、不暴露个人隐私
4. 说明本次沟通是计算机系研工组的相关要求，带班助理因负责多个年级，委派班长进行本年级的谈话

### 谈话内容

1. 近期上课和科研进展，有没有遇到什么困难需要系里帮助
2. 就业和生活上有没有什么需要支持的地方
3. 心理与身体健康状况
4. 对班级活动等有什么建议，或者有什么需要
5. 其他同学想聊、想反馈的问题

谈话结束时可以补一句：欢迎同学随时找带班助理和本年级班长沟通各方面的事情，班级永远是同学个人发展除所在实验室之外的坚强后盾。

### 数据汇总

谈话后于每周五 18:00 前，把本周数据通过清华云盘等方式共享给带班助理，由带班助理统一录入系统。

| 字段 | 内容 |
| :--- | :--- |
| 班长姓名 | 本次谈话的班长 |
| 同学姓名 | 被谈话同学 |
| 谈话时间 | 具体到日期与时段 |
| 谈话内容 | 原始录音 + 设备转写的文字稿 |
| 班长反馈 | 使用录音设备和谈话过程的情况、需要带班助理跟进的问题 |
