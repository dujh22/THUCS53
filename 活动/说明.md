## 📋 活动组织流程

每位加入五三大家庭的同学在整个研究生阶段完成一次活动的组织（一般活动在第三周或者第四周的周四下午举行，特殊情况会变化）。

负责同学需要依次完成如下工作：

| 时间节点 | 事项 | 对接人 |
| :--- | :--- | :--- |
| 每月第一天 | 进入"五三活动组织群" | 助理/支书 杜晋华 |
| 每月第一天 | 确认月度活动主题和推荐的组织方式，发在群内 | 支书 杜晋华 |
| 每月第一周 | 在班级群和党员群发布活动问卷：调查同学们【偏好的组织形式】【周四下午 15-18 点哪一个小时得空】【对活动的建议】，并把调研结果反馈到群内 | 组织委员 齐韵嘉 |
| 每月第二周 | 协调对应资源筹备活动（对接相关资源，提供图文进行活动报名推送发布：水木汇发布——群通知） | 党支书 杜晋华 |
| 每月第三周 | 活动现场签到，并对未到场同学进行二次确认。五三的党员务必参加，发展中的同学积极参加，群众可选参加 | 纪检委员 田钧锐 |
| 每月第三周 | 撰写活动总结稿，包含活动背景、活动过程、活动感悟，图文并茂（模版找支书要） | 负责同学本人 |
| 每月第三周 | 二次校验活动总结稿 | 宣传委员 夏箫 |
| 每月第三周 | 进行对应推送发布 | 支书 杜晋华 |
| 每月第四周 | 推送发布后更新对应行全部内容 | 负责同学本人 |
| 每月第四周 | 录入研究生支部系统、录入水木汇 | 支书 杜晋华 |
