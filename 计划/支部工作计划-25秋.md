# 支部工作计划（2025年秋）

## 一、党支部秋季学期工作思路（9—1月）

以习近平新时代中国特色社会主义思想为指导，全面贯彻党的二十大精神，深入学习贯彻习近平总书记关于教育、科技、人才的重要论述。坚持德智体美劳“五育并举”，落实“一月一轮”要求，统筹理论学习、警示教育、党员发展、联学共建和业务融合，推动党支部战斗堡垒作用和党员先锋模范作用有效发挥。

1. 理论学习：每月活动后统一安排一次理论学习，紧跟中央精神和学校党委部署。聚焦学习习近平总书记系列重要讲话、二十届三中全会和即将召开的二十届四中全会精神。
2. 党员发展与教育：按照发展计划推进党员发展、预备党员转正、新党员接收等。全学期开展两次集中培训（10月下旬、12月中上旬），并结合研讨计入组织生活。
3. 特色主题教育：党章学习、党史学习：本学期至少各一次；警示教育：至少一次，结合师德师风建设；联学共建：本学期组织一次与兄弟支部的共建活动。
4. 德智体美劳循环：每月活动突出一个侧重点，涵盖思想政治教育（德）、学术科研探索（智）、体育锻炼（体）、文化艺术（美）、劳动教育（劳）。

## 二、逐月工作计划

| 时间       | 工作安排                                                                                                                                                                                                                                                       |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 2025年09月 | 德育（思想政治与历史教育）：<br>1. 主题组织生活：纪念中国人民抗日战争暨世界反法西斯战争胜利80周年，观看抗战主题影片。<br>2. 理论学习：总结学习教育阶段工作，学习《整治形式主义为基层减负若干规定》。<br>3. 党员发展：明确本学期发展对象名单。                     |
| 2025年10月 | 智育（学术科研与学习能力）：<br>1. 重点任务：参加全校党员集中培训（10月下旬），并在党支部内开展专题研讨。<br>2. 理论学习：学习习近平总书记关于教育、科技、人才的重要论述。<br>3. 活动形式：结合科研课题，组织党员交流“科研诚信与创新精神”。                       |
| 2025年11月 | 体育（体魄与团队协作）：<br>1. 主题组织生活：开展体育团建（如支部羽毛球友谊赛），强化健康意识与集体凝聚力。<br>2. 理论学习：开展党章专题学习，结合党章条文讨论党员义务与责任。<br>3. 警示教育：组织师德师风警示教育，观看警示教育片并集中讨论。                   |
| 2025年12月 | 美育（文化熏陶与价值塑造）：<br>1. 重点任务：参加全校第二次党员集中培训（12月中上旬），并结合开展专题研讨。<br>2. 主题组织生活：结合“一二·九”运动90周年、“一二·一”运动80周年，开展纪念主题活动（如参观相关展览）。<br>3. 理论学习：学习习近平总书记关于全面深化改革的重要讲话精神，结合学校“十五五”规划编制开展交流。 |
| 2025年12月 | 劳动（实践教育与总结提升）：<br>1. 主题组织生活：开展校园或社区志愿服务（如图书整理、校园清扫、社区助老服务），弘扬劳动精神。<br>2. 理论学习：本学期党史专题学习，重点回顾清华党组织的发展历程与优良传统。<br>3. 总结工作：对本学期组织生活与理论学习情况进行总结通报，部署新学期工作。 |
| 2026年01月 | 学期总结与新学期谋划：<br>1. 主题组织生活：围绕本学期工作进行总结，围绕下一学期工作谋划，讨论个人与支部目标。<br>2. 理论学习：学习二十届四中全会精神，结合个人发展和学校“十四五”总结、“十五五”开局谈心得。<br>3. 联学共建：择机与兄弟支部联合开展一次线上/线下交流，互学互鉴。<br>4. 党员发展：做好预备党员转正、发展对象谈话等年初工作准备。 |
